WAIncognito APT Repository GPG Signed

Official Debian/Ubuntu APT repository for WAIncognito (WhatsApp Incognito Desktop).

Quick Setup (Recommended)

Runs the automated deb822 installer:

curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/apt/setup.sh | sudo bash
sudo apt install waincognito

Manual Setup (Modern deb822)

1. Download the repository source configuration:

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/apt/waincognito.gpg | sudo tee /etc/apt/keyrings/waincognito.gpg > /dev/null
curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/apt/waincognito.sources | sudo tee /etc/apt/sources.list.d/waincognito.sources > /dev/null
sudo apt update
sudo apt install waincognito

Automatic Updates

Once installed, updates are automatically delivered through standard package updates with conditional caching:

sudo apt update && sudo apt upgrade
