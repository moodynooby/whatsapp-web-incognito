WAIncognito APT Repository

Official Debian/Ubuntu APT repository for WAIncognito.

Quick Setup

curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/apt/setup.sh | sudo bash
sudo apt install waincognito

Manual Setup

Add the repository to your APT sources:

echo "deb [trusted=yes] https://moodynooby.github.io/whatsapp-web-incognito/apt/ stable main" | sudo tee /etc/apt/sources.list.d/waincognito.list
sudo apt update
sudo apt install waincognito

Updating

Once installed, updates are delivered automatically via standard package management:

sudo apt update && sudo apt upgrade
