WAIncognito RPM Repository GPG Signed

Official Fedora / RHEL / CentOS / openSUSE RPM repository for WAIncognito (WhatsApp Incognito Desktop).

Quick Setup (Recommended)

Runs the automated DNF repository installer:

curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/rpm/setup.sh | sudo bash
sudo dnf install waincognito

Manual Setup

1. Download repository configuration:

sudo curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/rpm/RPM-GPG-KEY-waincognito -o /etc/pki/rpm-gpg/RPM-GPG-KEY-waincognito
sudo curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/rpm/waincognito.repo -o /etc/yum.repos.d/waincognito.repo
sudo dnf install waincognito

Automatic Updates

Updates are delivered through standard dnf upgrade commands:

sudo dnf upgrade --refresh waincognito
