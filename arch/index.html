WAIncognito Arch Linux Repository GPG Signed

Official Arch Linux / Manjaro / EndeavourOS pacman repository for WAIncognito (WhatsApp Incognito Desktop).

Quick Setup (Recommended)

Runs the automated pacman repository installer:

curl -fsSL https://moodynooby.github.io/whatsapp-web-incognito/arch/setup.sh | sudo bash
sudo pacman -S waincognito

Manual Setup

Add the following section to /etc/pacman.conf:

[waincognito]
SigLevel = Optional TrustAll
Server = https://moodynooby.github.io/whatsapp-web-incognito/arch/$arch

Then sync and install:

sudo pacman -Sy waincognito

Automatic Updates

Delivered transparently alongside your regular system updates:

sudo pacman -Syu
